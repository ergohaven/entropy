# Bundled Fonts

Entropy bundles Noto Emoji as a fallback for the complete emoji picker and symbols used by the application.

- File: `NotoEmoji-Regular.ttf`
- Source: https://github.com/googlefonts/noto-emoji
- License: SIL Open Font License 1.1, copied in `OFL-NotoEmoji.txt`

The Text Expander emoji picker renders color artwork from Twemoji 17.0.2,
bundled through `twemoji-assets`.

- Source: https://github.com/jdecked/twemoji
- Graphics license: Creative Commons Attribution 4.0 International
- Copyright: Twitter, Inc and other contributors

The M4CR0Pad clock preview bundles the same font families used to generate
the numeric-only LVGL fonts in firmware: Ubuntu Sans/Mono, DejaVu
Sans/Serif/Mono, and Liberation Sans/Serif/Mono/Narrow. Ubuntu fonts are
licensed under the Ubuntu Font Licence 1.0; DejaVu fonts under the Bitstream
Vera/DejaVu licence; Liberation fonts under the SIL Open Font License 1.1.
